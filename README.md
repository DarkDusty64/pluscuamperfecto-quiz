# Pluscuamperfecto Quiz

Interaktives Spanisch-Quiz zum Pluscuamperfecto (había + Partizip).

- **Quiz:** 26 Fragen in 5 Teilen mit Sofort-Feedback und „Nur Fehler üben“
- **Unregelmäßige lernen:** Karteikarten für alle wichtigen unregelmäßigen Partizipien, sortiert nach Familien (-ierto, -cho, -to, -uesto, -uelto …), mit Beispielsätzen
- **Spickzettel** mit allen Formen von *haber*

Einfach `index.html` im Browser öffnen oder über GitHub Pages veröffentlichen.
