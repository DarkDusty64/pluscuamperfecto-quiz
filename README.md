# Pluscuamperfecto Quiz

Interaktives Spanisch-Quiz zum Pluscuamperfecto (había + Partizip).

- **Quiz:** 26 Fragen in 5 Teilen. Falsche Fragen kommen am Ende der Runde wieder, bis sie sitzen.
- **Unregelmäßige lernen (Smart Learning):** Spaced Repetition mit 5 Leveln für 27 Partizipien. Je höher das Level, desto schwerer die Karte (Partizip → Satzlücke → umgekehrt → komplette había-Form). Wiederholungen kommen nach 10 Min., 1, 3, 7 und 21 Tagen. Der Fortschritt bleibt im Browser gespeichert.
- **Merkhilfe und Spickzettel** sind eingeklappt und nur bei Bedarf da.

Einfach `index.html` im Browser öffnen oder über GitHub Pages veröffentlichen.
